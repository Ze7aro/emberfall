# Iconos individuales

Esta carpeta contiene 32 iconos separados de las dos láminas entregadas.

- Formato: PNG RGBA.
- Fondo: transparente.
- Contenido: píxeles originales de las imágenes, sin regeneración ni cambio de estilo.
- Nombres: numeración estable seguida de una descripción funcional.
- `index.csv`: relación entre cada archivo y su posición de origen.
- `preview_dark.jpg` y `preview_light.jpg`: controles visuales; no son assets del juego.

Las imágenes de entrada eran JPEG. La transparencia se reconstruyó eliminando el fondo oscuro de la primera lámina y el damero incrustado de la segunda. Puede existir compresión JPEG dentro de los propios iconos de origen.
